School logos for the NEPSAC Field Hockey site.

- One PNG per school, named in lower case with underscores (add new ones the same way).
- index.json maps a school's name on the site to its file. Add a line when you add a logo.
- Source of the first batch: girlsprephockey.us standings page (downloaded 2026-09-18). These are
  32-pixel-wide thumbnails, fine for small icons but they look soft if shown larger.
  Higher-resolution versions can replace the files with the same name.

Second batch (22 schools, small .webp files, about 40 px): taken from the NEPSAC member schools page,
nepsac.org/about/nepsac-member-schools. Replace any of them with a larger file of the same name if you find one.
